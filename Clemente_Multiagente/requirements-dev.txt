# --- Inspeccion del grafo (LangGraph Studio) ---------------------------------
# Levanta el servidor LangGraph local que Studio necesita para dibujar el grafo
# (`langgraph dev`). El extra [inmem] permite correrlo sin Docker ni base de datos.
langgraph-cli[inmem]

# --- Evaluacion (Sesion 22) --------------------------------------------------
# DeepEval aporta GEval (juicio con LLM sobre criterios propios) y las metricas
# de RAG. OJO: por defecto juzga con GPT-4 de OpenAI; en este proyecto se le pasa
# nuestro juez de Anthropic desde `tests/eval/juez.py`.
deepeval

# --- Seguridad / red teaming (Sesion 23) -------------------------------------
# DeepTeam genera ataques (inyeccion, escalamiento de permisos, manipulacion
# emocional) y los mapea al OWASP Top 10 para LLM. Leer `tests/seguridad/LEEME.md`
# antes de ejecutarlo: hay un aviso etico que aplica.
deepteam
